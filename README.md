# Qtune 光影音乐工作站

`Qtune` 是一个面向大众消费者的光影音乐工作站项目，通过投影、空间感应、音频引擎和移动应用，把任意平面转化为可交互的音乐创作界面。它的目标不是复制传统乐器，而是降低音乐创作门槛，提供更直观、更娱乐化、也更适合分享的创作体验。

## 项目定位

Qtune 由三部分组成：

- `硬件设备`：负责投影交互界面、识别用户触碰动作、输出声音并与外部设备连接
- `配套 App`：负责模式切换、内容编辑、录制分享、设备配置和账户同步
- `内容/社区平台`：负责模板、谱面、作品、创作者内容分发和社区互动

当前文档体系以 `Qtune v1.0` 为基线，覆盖产品定义、核心架构、硬件设计、App 设计、平台设计和版本路线图。

## 核心价值

- `极致便携`：将音乐创作入口从固定乐器转移到任意桌面、地面或墙面
- `视觉化交互`：让按键、打击垫、滑条和旋钮以可配置的投影界面呈现
- `低门槛创作`：通过直观界面和游戏化模式降低学习成本
- `天然适合分享`：演奏画面、手部动作和内容模板可以直接转化为可传播作品

## 当前版本范围

`V1.0` 聚焦以下能力：

- 便携式光影交互设备的核心硬件定义
- `光影钢琴` 与 `音乐画布` 两个核心模式
- 配套 App 的连接、配置、编辑和录制分享能力
- 内容/社区平台的基础模板分发和作品分享能力

以下方向保留在后续版本中推进：

- 完整的游戏化谱面体系
- 更强的社区运营和创作者分发机制
- 更丰富的 SDK 和开放生态
- 触觉反馈等下一代交互能力
