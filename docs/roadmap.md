# Qtune 路线图

## 1. 路线图原则

Qtune 的路线图按照“先建立核心闭环，再扩展内容和生态”的原则推进。每个版本都需要形成可独立验证的产品价值，而不是简单累积功能。

## 2. V1.0

目标：

- 建立 `设备 + App + 平台` 的基础闭环
- 形成清晰的产品定义和最小可用体验

范围：

- 完成便携设备核心硬件架构定义
- 上线 `光影钢琴` 和 `音乐画布`
- 提供基础录制、保存和分享能力
- 提供基础模板和作品浏览能力

不包含：

- 完整创作者生态
- 更复杂的开放接口
- 高级触觉反馈方案

## 3. V1.5

目标：

- 强化使用体验和内容消费深度

范围：

- 完善 `节奏冒险`
- 推进交互垫等配件方案
- 优化录制体验、模板分发和社区消费效率
- 提高设备稳定性和手感补偿体验

## 4. V2.0

目标：

- 从单一产品闭环扩展到内容生态和开放能力

范围：

- 建立更成熟的社区和创作者体系
- 逐步开放部分 SDK 或扩展能力
- 探索高级反馈、更多交互模式和跨场景能力

## 5. 版本递进关系

- `V1.0` 验证产品是否成立
- `V1.5` 验证产品是否好用、是否值得持续使用
- `V2.0` 验证平台和生态是否能成立
