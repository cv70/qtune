# Qtune 产品需求文档

## 1. 产品概述

Qtune 是一款融合光影交互、音乐创作、游戏化学习和内容分享的消费级电子音乐产品。它由便携式硬件设备、配套移动 App 与内容/社区平台组成，为用户提供从创作、练习到传播的完整闭环。

## 2. 产品目标

- 降低音乐创作和互动体验的使用门槛
- 提供高辨识度的视觉化音乐交互
- 支持便携场景下的即时创作和记录
- 建立内容模板、作品分享和社区传播基础设施

## 3. 目标用户

- `潮流玩家`
- `灵感捕手`
- `音乐萌新`
- `亲子家庭`

详细画像见 [product-overview.md](./product-overview.md)。

## 4. 硬件规格

| 模块 | 规格要求 | 备注 |
| --- | --- | --- |
| 投影模组 | 安全等级可用于消费级室内场景的投影/激光显示方案，分辨率不低于 `1280x720`，投射尺寸可调 | 需要保证普通室内光线下的可见性 |
| 感应模组 | 红外或等效空间感应方案，采样率不低于 `400fps`，交互延迟目标低于 `10ms` | 支持多点识别，目标至少 `10` 个独立触点 |
| 处理器 | 四核 ARM Cortex-A 级别处理平台或等效方案 | 承担识别、渲染、控制和音频处理 |
| 音频 | 内置双扬声器、`3.5mm` 音频输出、蓝牙音频传输 | 支持耳机和外部音响 |
| 连接性 | 蓝牙、USB-C | 用于配对、数据同步、充电和有线连接 |
| 电池 | `5000mAh` 级别可充电电池，持续使用续航目标不低于 `6` 小时 | 支持快充 |
| 物理尺寸 | 掌心级便携设备，重量和尺寸适合随身携带 | 目标接近“稍大的鹅卵石”体验 |
| 可选配件 | 超薄可卷曲交互垫 | 用于提升边界感、防滑和桌面适配性 |

## 5. 配套 App 功能

### 5.1 光影钢琴

- 提供标准键盘模式
- 支持 `88` 键或 `61` 键等布局切换
- 提供基础音色和力度曲线调节
- 支持与外部音乐工具进行控制器级联

### 5.2 音乐画布

- 支持用户绘制或摆放控制元件
- 元件形态包括打击垫、滑条、旋钮、触发区等
- 每个元件可定义音符、和弦、鼓点或效果参数
- App 侧编辑完成后可实时同步到设备投影界面

### 5.3 节奏冒险

- 提供游戏化节奏练习模式
- 以可视化提示引导用户完成节奏击打
- 支持难度递进、曲目扩展和成绩反馈

### 5.4 录制与分享

- 录制设备投影界面、手部动作和音频
- 支持画中画、滤镜、字幕和模板封面
- 支持保存为作品并发布到社区或外部平台

### 5.5 设备与账户

- 支持设备配对、校准配置和固件信息展示
- 支持账号登录、作品同步和模板同步
- 支持历史作品和收藏内容管理

## 6. 内容/社区平台功能

### 6.1 作品分享

- 用户可发布演奏作品、练习片段和创意玩法
- 支持点赞、评论、收藏和转发

### 6.2 模板与谱面分发

- 提供热门控制界面模板和节奏谱面
- 支持按风格、难度、创作者进行分类检索

### 6.3 创作者内容生态

- 支持创作者发布模板、谱面和挑战内容
- 支持专题活动、榜单和推荐流

### 6.4 平台治理

- 提供基础审核和违规处理能力
- 支持内容运营、推荐配置和活动管理

## 7. 用户体验要求

- `开机即用`：从开机到完成校准的链路尽量压缩
- `实时反馈`：触发、滑动、长按等操作都要有明确反馈
- `低延迟`：用户应感知到接近即时的触发响应
- `易理解`：首次使用无需复杂教程即可完成基础操作

## 8. 非功能要求

- `安全性`：投影和感应方案必须符合消费级室内使用要求
- `稳定性`：在常见室内光照和桌面材质下保持可用
- `续航`：满足移动使用场景的连续创作时长
- `可维护性`：设备端、App 端和平台端能力边界清晰
- `可扩展性`：支持后续扩展新模式、新模板和新平台能力

## 9. 技术可行性与风险

| 模块 | 风险点 | 应对方向 |
| --- | --- | --- |
| 多点识别 | 手部遮挡、并发触点、边缘误识别 | 提升感应方案精度，结合轨迹预测和动态补偿 |
| 环境干扰 | 强光、复杂材质、表面反光影响投影与识别 | 采用动态校准、滤光和环境适配策略 |
| 功耗与散热 | 投影和计算负载较高 | 做分模式功耗调度，并优化热设计 |
| 手感不足 | 缺少物理键程和触感 | 通过交互垫、反馈设计和后续触觉方案补足 |
| 内容冷启动 | 社区初期内容不足 | 通过官方模板、曲包和创作者合作启动内容生态 |

## 10. 商业模式摘要

- `硬件销售`：Qtune 主机和标配配件
- `配件销售`：交互垫、保护壳、定制周边
- `内容付费`：音色包、谱面、模板、会员权益
- `创作者合作`：品牌联动、艺术家模板和活动合作

## 11. 版本规划摘要

- `V1.0`：完成核心硬件定义、`光影钢琴`、`音乐画布`、基础录制分享和基础社区能力
- `V1.5`：强化 `节奏冒险`、优化交互垫体验、提升录制和内容分发能力
- `V2.0`：扩大社区和创作者生态，探索 SDK、更多互动模式和高级反馈能力
